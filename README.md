# Dither Press

Растровый станок в браузере: превращает картинку, GIF или видео в дизеринг в реальном времени.

**Открыть:** https://codegaus.github.io/dither-press/

Всё работает локально в браузере: файлы никуда не загружаются. Сборки и зависимостей нет: это один файл `index.html`.

## Что умеет

- **Источники:** PNG, JPG, WebP, GIF, MP4 и WebM. Файл можно выбрать, перетащить на страницу или вставить из буфера. Есть встроенные образцы: огонь, облака, сфера.
- **Алгоритмы на GPU (WebGL):** порог, случайный шум, Bayer 2×2 / 4×4 / 8×8, blue noise (void-and-cluster 64×64), горизонтальные и вертикальные линии, растровая точка с углом, штриховка.
- **Рассеивание ошибки на CPU (в Web Worker):** Floyd–Steinberg, Atkinson, Jarvis–Judice–Ninke, Stucki, Burkes, Sierra, с режимом «змейки».
- **Сетка по целому шагу:** каждая ячейка исходника усредняется в одну точку, а узор масштабируется тем же целым шагом. Поэтому точки остаются чёткими на любом размере.
- **Тон до дизеринга:** яркость, контраст, гамма, насыщенность, смещение порога, разброс полутонов, инверсия.
- **Цвет:**
  - два цвета;
  - палитры: 1-bit, Game Boy, Mac, Obra Dinn, CGA, PICO-8, янтарный монитор, e-ink, Sinking. Подбор по яркости или по ближайшему цвету;
  - постеризация по каналам.
- **Искажение узора:** волна, турбулентность, рябь от центра, линза и дрейф. Всё анимируется по времени.
- **Вид:** шторка «до / после», масштаб 1:1, шкала тонов, восемь пресетов.
- **Экспорт:** PNG без сглаживания; запись WebM на 5 секунд для анимированного результата.

## Как устроено

Упорядоченный дизеринг — это узор порогов поверх изображения. Каждый пиксель сравнивается с порогом в своей клетке узора и становится светлым или тёмным. Проход идёт в несколько этапов:

1. источник;
2. тон;
3. дизеринг на разрешении ячеек;
4. свечение;
5. вывод с увеличением без сглаживания.

Рассеивание ошибки считается последовательно, пиксель за пикселем, поэтому оно работает в отдельном потоке на процессоре.

## Локальный запуск

Откройте `index.html` в браузере. Для видео и вставки из буфера удобнее поднять любой статический сервер, например `python3 -m http.server`.

## Ограничения

- Анимированные GIF проигрываются там, где есть `ImageDecoder` (Chrome, Edge). В остальных браузерах берётся первый кадр.
- Запись WebM требует `MediaRecorder` с поддержкой WebM.

## Откуда идеи

- Матрица Байера (Bryce Bayer, 1973).
- Однобитный blue-noise-дизеринг из *Return of the Obra Dinn*.
- Приёмы из туториала Бена Марриотта по дизерингу в After Effects:
  - выравнивание сетки;
  - тон до порога;
  - добор полутонов;
  - искажение самого узора.
